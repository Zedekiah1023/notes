# 公开版数据边界与复现条件

本目录是seed416细粒度耗时对照的报告导出。仅保留正文、图表、汇总CSV/JSON和验证摘要。原始输入、逐请求账本、逐层事件、逐条RPC、存储区间、日志与完整归档保留在研究工作区，没有上传到notes。

汇总文件可以核对主表、A类阶段平均值、RPC操作均值和带宽积分结论。仅凭本公开包不能重画逐实例时间线，也不能从头重跑实验。

原实验使用12逻辑实例、60GB/s共享池、8192新token/步、4序列、SA八层逐层预取、Dynamo原生kv负载选择；原生进程栈K=10。seed416每臂只跑一次。输入SHA256见正文与环境摘要。

完整复现还需要固定DV实现、vLLM0.20.2、Dynamo1.5.0、Ascend0.20.2rc1、CPU模拟环境、模型tokenizer、冻结输入与网关/存储适配，以及本次默认关闭的计时探针。notes不包含这些完整资产，不应将汇总附件当作原始数据。
